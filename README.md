# AI × Dentistry

Қазақ тіліндегі интерактивті зерттеу жарияланымы.

**Тақырып:** «6 жыл стоматология оқып, ЖИ-ден қорқуға себеп бар ма?»  
**Автор:** Скакова Шугыла  
**Күні:** 14.09.2026

## Іске қосу

Репозиторийді жүктеп алып, `index.html` файлын браузерде ашыңыз. Орнату, жинақтау немесе сервер қажет емес. Түпнұсқа PDF сілтемесі жұмыс істеуі үшін PDF файлын сол қалтада сақтаңыз.

## Мүмкіндіктер

- 16 сауалнама сұрағы және PDF-тен алынған 56 пайыздық көрсеткіш.
- Тақырып бойынша сүзу, сұрақтарды таңдау және барлық жауапты кестеден оқу.
- Телефонға, планшетке және компьютерге бейімделген интерфейс.
- Пернетақтамен басқару және қозғалысты азайту баптауын қолдау.

## Технологиялар

HTML5, CSS3, Vanilla JavaScript. Диаграммалар сыртқы кітапханаларсыз жұмыс істейді. Google Fonts қолжетімсіз болса, жүйелік қаріптер қолданылады.

## Деректер туралы

Жалғыз дереккөз — репозиторийдегі зерттеу PDF құжаты. Сауалнама 1-курстағы 12 студенттің пікірін қамтиды. Нәтижелерді барлық стоматология немесе медицина студентіне жалпылауға болмайды. Пайыздар түпнұсқадағы дәлдікпен сақталған.
